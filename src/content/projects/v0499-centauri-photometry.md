## Scientific question

What is the pulsation period of V0499 Centauri, and what photometric distance can be derived from period-luminosity-metallicity relations and Gaia DR3 comparison?

## Data and materials

- Multi-band photometric observations from the Las Cumbres Observatory global telescope network
- Gaia DR3 parallax measurements for comparison

## Methods

- Multi-band photometry and folded light-curve construction
- Period determination using phase dispersion minimization, string-length minimization, harmonic analysis of variance, and Lomb-Scargle periodograms
- Photometric-distance analysis using period-luminosity-metallicity relations and extinction corrections
- Comparison with Gaia DR3 parallax measurements

## My contribution

- Conducted multi-band observational analysis using Las Cumbres Observatory data
- Analyzed telescope data and constructed folded light curves
- Contributed to period determination using multiple algorithms
- Supported photometric-distance analysis
